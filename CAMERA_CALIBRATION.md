# Калибровка камеры для правильной отрисовки разметки

## Проблема

Данные от TCP сервера приходят в **3D дорожной системе координат** (в метрах):
- `x` - боковое смещение (отрицательное = влево, положительное = вправо)
- `y` - расстояние вперед от камеры
- `z` = 0 (объекты на дороге)

Эти координаты нужно **спроецировать** на 2D изображение с учетом перспективы.

## Решение

Добавлена перспективная проекция с параметрами калибровки камеры в `MarkingOverlayProcessor`:

```cpp
struct CameraCalibration {
    float focalLengthPixels = 800.0f;      // Фокусное расстояние в пикселях
    float cameraHeightMeters = 1.2f;       // Высота камеры над дорогой (метры)
    float cameraPitchDeg = -5.0f;          // Наклон камеры (градусы, "-" = вниз)
    float metersPerPixelAtGround = 0.02f;  // Масштаб для запасного варианта
    int imageWidth = 1920;
    int imageHeight = 1080;
};
```

## Как настроить параметры

### 1. Фокусное расстояние (`focalLengthPixels`)

**Что это:** Определяет, насколько "увеличено" изображение камеры.

**Как подобрать:**
- Начните с `800` для Full HD (1920x1080)
- Если объекты слишком маленькие → **увеличьте** (900, 1000, 1200)
- Если объекты слишком большие → **уменьшите** (700, 600, 500)

**Формула для расчета из реальной камеры:**
```
focalLengthPixels = (focalLength_mm * imageWidth_px) / sensorWidth_mm
```

Например:
- Камера: 8mm фокусное расстояние, сенсор 1/3" (4.8mm ширина)
- Изображение: 1920 пикселей
- Фокусное расстояние = (8 * 1920) / 4.8 ≈ **3200 пикселей**

### 2. Высота камеры (`cameraHeightMeters`)

**Что это:** Высота установки камеры над поверхностью дороги.

**Типичные значения:**
- Легковой автомобиль: `1.0 - 1.3` метра
- Грузовик/автобус: `2.0 - 2.5` метра
- Камера на капоте: `0.8 - 1.0` метра

**Как измерить:**
Измерьте расстояние от линзы камеры до поверхности дороги.

### 3. Наклон камеры (`cameraPitchDeg`)

**Что это:** Угол наклона камеры вниз к дороге (в градусах).

**Типичные значения:**
- `-5°` до `-15°` для камер на лобовом стекле
- `-20°` до `-30°` для камер, направленных вниз
- `0°` для горизонтальной камеры

**Знак:**
- Отрицательное значение (`-5`) = камера смотрит **вниз**
- Положительное значение (`+5`) = камера смотрит **вверх**

**Как измерить:**
Используйте инклинометр (приложение на телефоне) или визуально оцените по горизонту на изображении.

### 4. Масштаб для запасного варианта (`metersPerPixelAtGround`)

**Что это:** Упрощенный масштаб для объектов очень близко к камере.

**Типичные значения:**
- `0.01` - мелкий масштаб (объекты крупнее)
- `0.02` - средний (по умолчанию)
- `0.05` - крупный масштаб (объекты мельче)

## Пример настройки через C++ код

В `AppController.cpp` или при инициализации:

```cpp
// Получить процессор
auto* overlayProcessor = getMarkingOverlayProcessor();

// Настроить параметры камеры
overlayProcessor->setCameraFocalLength(1000.0f);    // Фокусное расстояние
overlayProcessor->setCameraHeight(1.2f);            // Высота 1.2м
overlayProcessor->setCameraPitch(-10.0f);           // Наклон 10° вниз
overlayProcessor->setMetersPerPixel(0.02f);         // Масштаб
```

## Процесс калибровки пошагово

### Шаг 1: Проверьте реальные данные

Посмотрите на логи объектов:
```
MarkingObject from domain: x=-0.8 y=3.7 length=0.6 width=3.1
```

Это означает:
- Объект на **0.8м влево** от центра полосы
- На расстоянии **3.7м вперед** от камеры
- Размер: **0.6м × 3.1м**

### Шаг 2: Сравните с видео

Включите отрисовку и проверьте:
1. **Горизонтальное положение:** Объекты слева/справа совпадают?
   - Если нет → настройте `focalLengthPixels`

2. **Вертикальное положение:** Ближние объекты внизу, дальние вверху?
   - Если нет → настройте `cameraPitchDeg` и `cameraHeightMeters`

3. **Масштаб:** Размеры объектов соответствуют реальным?
   - Если нет → настройте `focalLengthPixels`

### Шаг 3: Точная подгонка

1. Найдите объект с известными координатами (например, разметку на дороге)
2. Измерьте его реальное положение в метрах от камеры
3. Подберите параметры так, чтобы отрисовка совпадала

## Рекомендуемая последовательность настройки

1. **Начните с `cameraHeightMeters`** - измерьте физически
2. **Установите `cameraPitchDeg`** - оцените по изображению
3. **Подберите `focalLengthPixels`** - по масштабу объектов
4. **Тонко настройте** все три параметра итеративно

- Объекты вдалеке должны быть выше на экране

## Часто задаваемые вопросы

**Q: Объекты отрисовываются не там где надо**
A: Проверьте порядок координат - убедитесь что `x` это боковое смещение, а `y` это расстояние вперед

**Q: Объекты слишком большие/маленькие**
A: Измените `focalLengthPixels` - увеличьте для уменьшения объектов

**Q: Перспектива неправильная (дальние объекты не уменьшаются)**
A: Проверьте `cameraPitchDeg` - возможно камера смотрит не под тем углом

**Q: Объекты "прыгают" при изменении расстояния**
A: Это нормально при неточной калибровке - подберите параметры точнее
