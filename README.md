# Dashboard for Road Marking

Десктопное приложение на C++/Qt6 для визуализации и анализа дорожной разметки в реальном времени. Получает данные о полосах движения и дорожных объектах по TCP-протоколу и отображает их на интерактивной 3D-панели вместе с видеопотоком.

## Основные возможности

- **Визуализация разметки в реальном времени** - отображение полос движения, пешеходных переходов, стрелок, стоп-линий
- **3D-панель приборов** - изометрический вид дороги с 3D-моделью автомобиля на Qt Quick 3D
- **Интеграция видеопотока** - поддержка UDP multicast и RTSP через GStreamer
- **Система предупреждений** - оповещения о сходе с полосы и приближении к пешеходному переходу
- **Наложение данных на видео** - отрисовка обнаруженных объектов поверх видеокадра

## Технологии

| Компонент | Назначение |
|-----------|------------|
| Qt6 | UI, QML, 3D-графика |
| C++17 | Основной язык |
| CMake 3.16+ | Система сборки |
| GStreamer 1.0 | Видеопотоки и кодеки |

## Сборка и запуск

### Зависимости

```bash
# Установка зависимостей (Ubuntu/Debian)
make install-deps
```

### Сборка

```bash
# Debug-сборка
make build

# Release-сборка
make release

# Быстрая пересборка
make fast

# Полная пересборка
make rebuild
```

### Запуск

```bash
make run

# Или с параметрами
./build/dashboard -H 192.168.1.100 -P 9000
```

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `-H`, `--host` | IP-адрес сервера данных |
| `-P`, `--port` | Порт TCP-соединения |
| `--help` | Справка |

## TCP-протокол V2

Бинарный протокол для передачи данных о разметке.

**Структура кадра:**
```
[SYNC 2B] [HEADER 9B] [PAYLOAD] [CRC16 2B]
```

**Типы сообщений:**
- `0x01` - LANE_LINES (полосы движения)
- `0x02` - ROAD_OBJECTS (дорожные объекты)

**Система координат:**
- Y - вперед (направление движения)
- X - вправо
- Начало координат - камера

Подробное описание протокола: [TCP_PROTOCOL_V2.md](TCP_PROTOCOL_V2.md)
