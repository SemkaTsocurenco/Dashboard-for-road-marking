# TCP Протокол V2

## Обзор

Приложение получает данные о дорожной разметке по TCP протоколу версии 2. Протокол использует бинарный формат с фиксированной структурой кадров.

## Структура кадра

```
┌──────────┬──────────────┬─────────────────┬──────────┐
│  SYNC    │   HEADER     │    PAYLOAD      │   CRC    │
│  1 byte  │   9 bytes    │   variable      │  2 bytes │
│  0xAA    │              │                 │          │
└──────────┴──────────────┴─────────────────┴──────────┘
```

### Общая структура

| Поле | Размер | Описание |
|------|--------|----------|
| Sync | 1 байт | Синхробайт `0xAA` |
| Header | 9 байт | Заголовок кадра |
| Payload | переменный | Полезная нагрузка |
| CRC16 | 2 байта | Контрольная сумма (Little Endian) |

## Заголовок (Header)

```
Offset  Size  Field
──────────────────────────────
0       1     Version
1       1     Message Type
2       1     Sequence Number
3       4     Timestamp (ms)
7       2     Payload Length
──────────────────────────────
Total:  9 bytes
```

### Поля заголовка

| Поле | Тип | Описание |
|------|-----|----------|
| Version | uint8 | Версия протокола (текущая: `0x02`) |
| Message Type | uint8 | Тип сообщения |
| Sequence | uint8 | Номер последовательности (0-255, циклический) |
| Timestamp | uint32 | Временная метка в миллисекундах (Little Endian) |
| Payload Length | uint16 | Длина payload в байтах (Little Endian) |

### Типы сообщений (Message Type)

| Код | Название | Описание |
|-----|----------|----------|
| `0x01` | LaneLines | Линии разметки и состояние полос |
| `0x02` | RoadObjects | Объекты дорожной разметки |

## Контрольная сумма (CRC16)

- Алгоритм: CRC-16/CCITT-FALSE
- Полином: `0x1021`
- Начальное значение: `0xFFFF`
- Порядок байт: Little Endian

**Область расчёта:** Header + Payload (без Sync)

**Пример расчёта (C++):**

```cpp
uint16_t crc16_ccitt(const uint8_t* data, size_t length) {
    uint16_t crc = 0xFFFF;
    for (size_t i = 0; i < length; i++) {
        crc ^= (uint16_t)data[i] << 8;
        for (int j = 0; j < 8; j++) {
            if (crc & 0x8000) {
                crc = (crc << 1) ^ 0x1021;
            } else {
                crc <<= 1;
            }
        }
    }
    return crc;
}
```

## Сообщение LaneLines (0x01)

Содержит информацию о линиях разметки и состоянии полосы движения.

### Структура Payload

```
Offset  Size  Field
──────────────────────────────
0       1     Line Count
1       N*23  Lines Array
N*23+1  4     Center Offset (м)
N*23+5  1     Quality
──────────────────────────────
```

### Структура элемента Line

```
Offset  Size  Field
──────────────────────────────
0       1     Line ID
1       1     Style
2       1     Color
3       4     Offset (м)
7       4     Confidence
11      4     Poly A (y²)
15      4     Poly B (y)
19      4     Poly C (const)
──────────────────────────────
Total:  23 bytes per line
```

### Поля Line

| Поле | Тип | Описание |
|------|-----|----------|
| Line ID | uint8 | Идентификатор линии (0 = левая, 1 = правая) |
| Style | uint8 | Стиль линии (см. таблицу ниже) |
| Color | uint8 | Цвет линии (см. таблицу ниже) |
| Offset | float | Смещение линии от центра авто (метры) |
| Confidence | float | Уверенность детекции (0-100) |
| Poly A | float | Коэффициент при y² |
| Poly B | float | Коэффициент при y |
| Poly C | float | Свободный член |

### Стили линий (Style)

| Код | Название | Описание |
|-----|----------|----------|
| `0x00` | Unknown | Неизвестный тип |
| `0x01` | Solid | Сплошная линия |
| `0x02` | Dashed | Прерывистая линия |
| `0x03` | Double | Двойная линия |

### Цвета линий (Color)

| Код | Название | Описание |
|-----|----------|----------|
| `0x00` | Unknown | Неизвестный цвет |
| `0x01` | White | Белый |
| `0x02` | Yellow | Жёлтый |
| `0x03` | Red | Красный |

### Дополнительные поля LaneLines

| Поле | Тип | Описание |
|------|-----|----------|
| Center Offset | float | Смещение авто от центра полосы (метры) |
| Quality | uint8 | Качество детекции (0-100) |

### Полиномиальная модель линии

Каждая линия описывается полиномом второй степени:

```
x = A * y² + B * y + C
```

Где:
- `x` — горизонтальное смещение (метры)
- `y` — расстояние вперёд от камеры (метры)
- `A`, `B`, `C` — коэффициенты полинома

**Пример генерации точек:**

```cpp
std::vector<QPointF> generateLinePoints(float a, float b, float c,
                                        float y_start, float y_end,
                                        int point_count) {
    std::vector<QPointF> points;
    float step = (y_end - y_start) / (point_count - 1);

    for (int i = 0; i < point_count; i++) {
        float y = y_start + i * step;
        float x = a * y * y + b * y + c;
        points.push_back(QPointF(x, y));
    }
    return points;
}
```

## Сообщение RoadObjects (0x02)

Содержит информацию об объектах дорожной разметки (пешеходные переходы, стрелки, стоп-линии).

### Структура Payload

```
Offset  Size  Field
──────────────────────────────
0       1     Object Count
1       N*25  Objects Array
──────────────────────────────
```

### Структура элемента Object

```
Offset  Size  Field
──────────────────────────────
0       1     Class ID
1       4     X (м)
5       4     Y (м)
9       4     Width (м)
13      4     Height (м)
17      2     Center X (px)
19      2     Center Y (px)
21      2     Width (px)
23      2     Height (px)
25      4     Confidence
──────────────────────────────
Total:  29 bytes per object
```

### Поля Object

| Поле | Тип | Описание |
|------|-----|----------|
| Class ID | uint8 | Тип объекта (см. таблицу ниже) |
| X | float | Позиция X в метрах (относительно авто) |
| Y | float | Позиция Y в метрах (расстояние вперёд) |
| Width | float | Ширина объекта в метрах |
| Height | float | Высота/длина объекта в метрах |
| Center X | int16 | Центр X в пикселях изображения |
| Center Y | int16 | Центр Y в пикселях изображения |
| Width px | int16 | Ширина в пикселях |
| Height px | int16 | Высота в пикселях |
| Confidence | float | Уверенность детекции (0-100) |

### Типы объектов (Class ID)

| Код | Название | Описание |
|-----|----------|----------|
| `0x00` | Unknown | Неизвестный объект |
| `0x02` | Crosswalk | Пешеходный переход |
| `0x05` | StopLine | Стоп-линия |
| `0x0B` | ArrowLeft | Стрелка влево |
| `0x0C` | ArrowStraight | Стрелка прямо |
| `0x0D` | ArrowRight | Стрелка вправо |
| `0x0E` | ArrowLeftRight | Стрелка влево-вправо |
| `0x0F` | ArrowStraightLeft | Стрелка прямо-влево |
| `0x10` | ArrowStraightRight | Стрелка прямо-вправо |
| `0x11` | ArrowUturn | Стрелка разворота |

## Система координат

### Координаты в метрах

```
        +X (вправо)
        ↑
        │
        │ Y (вперёд)
────────┼────────→
        │
        │
    Камера/Авто (0, 0)
```

- **Начало координат:** позиция камеры/автомобиля
- **Ось X:** горизонтальное смещение (положительное = вправо)
- **Ось Y:** расстояние вперёд от камеры

### Координаты в пикселях

```
(0,0) ─────────→ +X
  │
  │
  ▼
  +Y
```

- **Начало координат:** левый верхний угол изображения
- **Ось X:** горизонтальная позиция (слева направо)
- **Ось Y:** вертикальная позиция (сверху вниз)

## Конечный автомат парсера

```
                 ┌─────────────┐
                 │ WaitingSync │◄────────────┐
                 └──────┬──────┘             │
                        │ 0xAA               │ Error/Reset
                        ▼                    │
                 ┌─────────────┐             │
                 │ReadingHeader│─────────────┤
                 └──────┬──────┘             │
                        │ 9 bytes            │
                        ▼                    │
                ┌──────────────┐             │
                │ReadingPayload│─────────────┤
                └──────┬───────┘             │
                       │ payload_len bytes   │
                       ▼                     │
                 ┌──────────┐                │
                 │ReadingCrc│────────────────┘
                 └─────┬────┘
                       │ CRC OK
                       ▼
                 ┌──────────┐
                 │ Dispatch │
                 │ Message  │
                 └──────────┘
```

### Состояния

| Состояние | Описание | Переход |
|-----------|----------|---------|
| WaitingSync | Ожидание синхробайта 0xAA | → ReadingHeader при 0xAA |
| ReadingHeader | Чтение 9 байт заголовка | → ReadingPayload после 9 байт |
| ReadingPayload | Чтение payload | → ReadingCrc после payload_len байт |
| ReadingCrc | Чтение 2 байт CRC | → WaitingSync, dispatch если CRC OK |

## Обработка ошибок

### Ошибки протокола

| Ошибка | Описание | Действие |
|--------|----------|----------|
| Invalid Sync | Байт ≠ 0xAA | Продолжить поиск 0xAA |
| CRC Mismatch | CRC не совпадает | Отбросить кадр, вернуться к WaitingSync |
| Unknown Message Type | Неизвестный тип | Логировать, отбросить кадр |
| Timeout | Нет данных | Сброс парсера |

### Восстановление

При ошибке парсер:
1. Сбрасывает буфер
2. Возвращается в состояние WaitingSync
3. Продолжает поиск следующего 0xAA

## Статистика и диагностика

### Метрики парсера

| Метрика | Описание |
|---------|----------|
| frames_received | Успешно принятых кадров |
| frames_dropped | Отброшенных кадров (CRC error) |
| bytes_received | Всего принято байт |
| last_sequence | Последний номер последовательности |

### Обнаружение потерь

```cpp
// Проверка пропуска кадров
uint8_t expected = (last_sequence + 1) % 256;
if (current_sequence != expected) {
    int lost = (current_sequence - expected + 256) % 256;
    LOG_WARN("Lost {} frames", lost);
}
```

## Рекомендации по реализации

### Буферизация

```cpp
// Рекомендуемый размер буфера
constexpr size_t BUFFER_SIZE = 4096;

// Максимальный размер payload
constexpr size_t MAX_PAYLOAD_SIZE = 1024;
```

### Потокобезопасность

- Парсер должен вызываться из одного потока
- Результаты парсинга передаются через сигналы/коллбэки
- Обработчики сообщений могут выполняться в другом потоке

### Производительность

1. Использовать пул буферов вместо аллокаций
2. Избегать копирования данных
3. Парсить payload только при необходимости (lazy parsing)
