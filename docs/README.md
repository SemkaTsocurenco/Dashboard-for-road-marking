# Dashboard for Road Marking - Документация

## Обзор

**Dashboard for Road Marking** — это десктопное приложение для визуализации дорожной разметки в реальном времени. Приложение получает данные о разметке по TCP протоколу и отображает их в виде интерактивной 3D сцены с изометрическим видом, а также накладывает визуализацию на видеопоток.

### Основные возможности

- **3D визуализация дороги** — изометрический вид с моделью автомобиля
- **Отображение линий разметки** — сплошные, прерывистые, двойные линии разных цветов
- **Объекты разметки** — пешеходные переходы, стрелки направления, стоп-линии
- **Система предупреждений** — предупреждения о сходе с полосы, приближении к пешеходному переходу
- **Видеопоток с оверлеем** — наложение разметки на живое видео
- **Индикатор смещения** — визуализация положения автомобиля относительно центра полосы

## Быстрый старт

### 1. Сборка проекта

```bash
# Клонирование репозитория
git clone <repository-url>
cd Dashboard-for-road-marking

# Создание директории сборки
mkdir build && cd build

# Конфигурация и сборка
cmake ..
make -j$(nproc)
```

### 2. Настройка конфигурации

Отредактируйте `config.json`:

```json
{
  "network": {
    "host": "127.0.0.1",
    "port": 9000
  },
  "video": {
    "source_url": "udp://239.0.0.1:5000"
  }
}
```

### 3. Запуск приложения

```bash
./Dashboard-for-road-marking --config config.json
```
